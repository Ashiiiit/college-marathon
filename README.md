ATAL Marathon Registration Portal

A premium, full-stack **Next.js 14** application engineered for the official **ATAL Marathon × Meraki'26** event. The platform features a high-performance frontend powered by **GSAP** animations, secure real-time data management via **Supabase (PostgreSQL)**, and integrated payment processing through the **Razorpay API**. 

Successfully deployed in production to handle live registrations, participant data capture, and financial transactions.

🔗 **Live Project:** atalrun.vercel.app

---
Tech Stack: Next.js, Tailwind CSS, GSAP, Supabase, Razorpay.
